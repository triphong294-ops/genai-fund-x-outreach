# GenAI Fund — AI & Robotics Builder Outreach Prototype

A human-in-the-loop (HITL) outreach tool built for **GenAI Fund** to discover AI & Robotics builders/founders on X, extract real evidence from their profiles and recent posts, draft personalized DMs without hallucination, and safely execute 1-on-1 outreach with strict idempotency.
